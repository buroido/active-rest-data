## データの概要

### sessions.csv

13回の実験セッションにおける，ゲームタイトル，作業内容，作業・休憩時間，および各評定値（5件法）を含む匿名化データです．

#### 列の説明

| 列名                | 説明                               |
| ------------------- | ---------------------------------- |
| session_id          | セッション番号（1〜13）            |
| participant_id      | 参加者ID（P1〜P8，匿名化済み）     |
| game_title          | 休憩中にプレイしたゲームタイトル   |
| game_genre          | ゲームのジャンル                   |
| task_type           | 直前の作業内容（カテゴリ化済み）   |
| task_duration_min   | 作業時間（分）                     |
| rest_duration_min   | 休憩時間（分）                     |
| fatigue_before_rest | 作業終了時の疲労感（1〜5）         |
| loss_after_rest     | 休憩終了時の喪失感のなさ（1=非常に感じた ／ 5=全く感じなかった）※逆転項目 |
| extend_intention    | 休憩時間を延長したい気持ち（1〜5） |
| task_return_ease    | 作業に戻りやすいと感じたか（1〜5） |
| detachment          | 心理的デタッチメント（1〜5）     |
| relaxation          | リラクゼーション（1〜5）           |
| mastery             | マスタリー（1〜5）                 |
| control             | コントロール（1〜5）               |
| rest_satisfaction   | 総合的な休憩満足度（1〜5）         |
| self_efficacy       | 状態自己効力感（1〜5）             |
| being_away          | 作業とは別の場所や世界にいるような感覚（1〜5） |
| fascination         | 活動に自然と注意が向いた感覚（1〜5）           |
| extent              | 短時間でもまとまった体験として感じられたか（1〜5） |
| compatibility       | 今求めていた休憩に合っていたか（1〜5）         |

#### 評定スケール

全項目5件法（1=全くそう思わない ／ 5=非常にそう思う）

---

## 参加者について

- 実験参加者：8名（P1〜P8）
- 全員大学生男性，年齢19〜23歳（平均21.9歳）
- 参加者は同一研究室の関係者として募集
- 合計実験セッション数：13回（1名が1〜3回実施）

自由記述の生テキストは，小集団（8名）における再特定リスクを考慮し，本リポジトリには含めていません．

---

## 倫理・データ管理

- 全参加者から実験参加同意を取得済み
- 公開データは学籍番号を含まない匿名化済みデータです
- 自由記述テキストは研究者が適切に管理し，本リポジトリには含めていません

### rest_views.csv

実験参加同意フォームで取得した，参加者の休憩観データです．
実験に参加した8名（P1〜P8）のみを対象とし，同意フォームに回答したが実験に参加しなかった者のデータは含みません．

#### 列の説明

| 列名                   | 説明                                     |
| ---------------------- | ---------------------------------------- |
| participant_id         | 参加者ID（P1〜P8，匿名化済み）           |
| usual_rest_activity    | 普段の休憩でしていること（自由記述）     |
| usual_rest_duration    | 普段の1回あたりの休憩時間（自由記述）    |
| q1_rest_views          | 休憩の意味づけ（複数選択，カンマ区切り） |
| q2_most_important_view | 最も重要と感じる休憩観（単一選択）       |

休憩観の理由に関する自由記述（q3）は小集団における再特定リスクを考慮し，本リポジトリには含めていません．
